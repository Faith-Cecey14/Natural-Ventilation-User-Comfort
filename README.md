# Assessment of Natural Ventilation on Users' Comfort in a Lecture Hub

## Project Overview

This project investigated whether natural ventilation in a university lecture hub provides adequate indoor comfort for occupants. The study combined field measurements with statistical analysis to evaluate ventilation performance and user Satisfaction 

## Objectives

- Assess the adequacy of natural ventilation.
- Evaluate occupants' comfort.
- Determine the relationship between ventilation and comfort.


## Tools Used

- SPSS
- Microsoft Excel
- Questionnaire Survey
- Descriptive Statistics
- Pearson Correlation Analysis

## Dataset

The dataset consists of questionnaire responses and building measurements collected from occupants of the lecture hub.

---

## Methodology

1. Data collection through questionnaires.
2. Data cleaning in Microsoft Excel.
3. Statistical analysis in SPSS.
4. Interpretation of results.
5. Recommendations based on findings.

---

## Key Findings

- Window-to-Floor Ratio was below recommended standards.
- Occupants reported poor air circulation.
- A significant positive relationship was found between natural ventilation and users' comfort.
